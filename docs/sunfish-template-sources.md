## การอ่านหลักฐานอย่างถูกต้อง

- ชื่อไฟล์และ alt text ใช้ช่วยค้นหา ไม่ใช่ข้อพิสูจน์ว่าภาพเป็นหน้าที่ชื่อนั้นระบุเสมอไป
- ภาพที่อยู่ใต้หัวข้อของ feature อาจเป็นภาพการตลาดหรือเพียงส่วนหนึ่งของ UI
- ข้อมูลใน screenshot เป็นข้อมูลของ reference; ไม่คัดลอกชื่อบุคคลหรือยอดธุรกิจมาเป็นข้อมูล hrmic.ai
- เมื่อมีสิทธิ์เข้าดูแอปตัวอย่างจริงในอนาคต ให้เติม URL, release/theme, role, viewport, state และวันที่ของหลักฐานเพิ่มก่อนยกระดับเป็น specification
